一张图片一页，按列表顺序生成 PDF。支持常见图片及 HEIC / TIFF 等，动画处理首帧；透明区域用白色背景。

    支持 DOCX、TXT、Markdown、HTML，保留基础文字、标题、列表、表格内容及内嵌 PNG/JPEG；复杂 Office 排版会重排，不读取外部图片。旧 DOC 请先转为 DOCX。

    文字版需要 PDF 自带文字层，多栏、表格可能需要调整；扫描件请选择图片版。图片版不提供文字编辑或 OCR。

    最多 16 个文件、单次 200 页、输入总量 128 MiB；PDF 单文件 64 MiB，文档 32 MiB，输出 64 MiB。图片导出为 ZIP，按页码命名。过大页面会限制像素以适应设备；加密 PDF 可填写各文件的打开密码；合并保留页面文字和矢量内容，输出 PDF 不加密，不合并书签、表单或附件。
